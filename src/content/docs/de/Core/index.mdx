**BuildMC-Core** ist ein Custom Plugin, das speziell für BuildMC-SMP-Server entwickelt wurde.

Die meisten Minecraft-Server verlassen sich auf Plugins von Drittanbietern, um dem Spielerlebnis neue Funktionen zu verleihen. Mit der Zeit sind wir aber auf Limitierungen, Bugs und inkompatible Features dieser Plugins gestoßen. Aus diesem Grund haben wir unsere eigene Lösung entwickelt, die perfekt auf die Bedürfnisse unseres Servers zugeschnitten ist.

BuildMC-Core vereint essenzielle Spiel- und Admin-Tools in einem einzigen, leistungsstarken Plugin. Es bietet dabei mehrsprachige Unterstützung, tiefgehende Konfigurationsmöglichkeiten und eine erweiterbare API für Entwickler.

## Kernfunktionen (Core Features)

---

### Claim System
Ein robustes Claims-System, um deine Chunks zu schützen. Du kannst damit Berechtigungen und Schutzbereiche verwalten. Es unterstützt sowohl Spieler als auch Teams.

### Spawn Elytra
Ermöglicht es Spielern, vom Respawn-Punkt abzuheben und zu gleiten, selbst wenn sie keine Elytras ausgerüstet haben.

### End Event
Die End-Dimension ist standardmäßig gesperrt. Admins können diese freischalten, was einen im Spiel angekündigten Event auslöst.

### Player Heads
Beim Tod lassen Spieler ihre Köpfe fallen – ein System, das wie eine Trophäe funktioniert und sammelbar ist.

### Status
Ein Status-System, mit dem Spieler einen stilisierten Präfix vor ihrem Namen setzen können. Enthält Berechtigungen und Regeln.

### Translations
Volle Unterstützung für Deutsch und Englisch direkt out of the box.

### Detailed Configuration
Jedes System kann feinabgestimmt werden, um perfekt zu den Spiel- und Admin-Vorlieben deines Servers zu passen.

### Developer API
BuildMC-Core beinhaltet eine API, mit der du Erweiterungen schreiben und das interne Verhalten des Plugins modifizieren kannst.
