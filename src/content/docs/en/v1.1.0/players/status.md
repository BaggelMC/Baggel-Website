A **Status** is a small piece of text that appears in front of your name in the game. You can assign yourself a status using `/status set <status>` and remove it using `/status remove`.

Statuses are added by administrators in the server configuration. In BuildMC events, players are often allowed to submit their own statuses. A status is defined using the [MiniMessage](https://docs.papermc.io/adventure/minimessage/format/) format.

We recommend you to use our own [MiniMessage Editor](/tools/minimessage/) to design your status.

You can alternatively also use the [Official MiniMessage Viewer](https://webui.advntr.dev) or the [RGBirdflop Editor](https://www.birdflop.com/resources/rgb/) _(if you set `Color Format` to `MiniMessage`)_.

> Note: Not all statuses may be available to you. The admins control which tags can be used by everyone, by specific teams, or by players with certain permissions. You will only see and be able to use the statuses allowed for your account.
