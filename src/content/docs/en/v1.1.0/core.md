**BuildMC-Core** is a custom plugin specially developed for BuildMC-SMP servers.

Most Minecraft servers rely on third-party plugins to add new functionality to the Minecraft experience. Over time, we encountered limitations, bugs and mismatched features in the plugins we relied on. To address this, we developed an in-house solution that perfectly matches our server's needs.

BuildMC-Core brings together essential gampleay and administrative tools, wrapped in a single, high-performance plugin with multilingual support, deep configuration options and an extensible API for developers.

# Core features:

## Claim System:
A robust claiming system to protect your chunks. It includes a UI for managing permissions and protections. It supports both players and teams.

## Spawn Elytra:
Allows players to launch and glide from spawn, even without an elytra equipped.

## End Event:
The End dimension starts locked and can be unlocked by admins, triggering an in-game announcement.

## Player Heads:
Players drop their heads upon death, adding a trophy-style collectible system.

## Status:
A status system allowing players to set a stylized prefix in front of their name. Includes permissions and rules.

## Translations:
Full German and English support out of the box.

## Detailed Configuration:
Every system can be fine-tuned to match your sever's gameplay and administrative preferences.

## Developer API:
BuildMC-Core includes an API to write extensions and modify the internal behavior of the plugin.
